This page is provided for convenient viewing without installation. For the fuller experience and better results when testing the API, download and use the main app: it makes on-demand requests, supports more device controls, and offers authorized hourly access. Both editions depend on the same upstream sensor data; the main app does not improve sensor accuracy.

Web limitations: four fixed devices, public latest readings only, and scheduled snapshots instead of live browser-to-API requests. No private tokens, hourly history, or device additions. Internet is required; Python is not required for visitors.

Null and missing values remain unavailable. Raw PM₂.₅ is displayed; no AQI is calculated in this web preview. A stale label means the measurement is over 20 minutes old. The source may already be delayed when collected.

What to expect

  • Measurement time comes from the device/API. Collection time tells you when GitHub last fetched that record. All displayed times are UTC.
  • Failed collection may retain an earlier reading, explicitly labelled with its original timestamps. Zero remains zero; missing data is never replaced with an invented value.
  • The page reloads published JSON every five minutes while open. Publishing schedules are approximate; a collection gap over 45 minutes is flagged.
  • GitHub can disable scheduled jobs after 60 days without repository activity. If updates stop, check the collection workflow or use the main app.
  • Unknown parameter units remain unspecified. Gas-related indices/signals are not calibrated NO₂ or O₃ concentrations. This is a demonstration, not an official AirGradient product.
